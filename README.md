# <img src="bookify.svg" width="25"/> Bookify

### **👁️ Overview**
Accommodation Booking Web Application - 2025.

<p align="justify">
    Bookify is a user-friendly accommodation booking web application that allows users to search for and reserve places to stay with ease. Designed to provide a smooth booking experience, the application helps users browse available accommodations, review details, and complete reservations in an organized and efficient way. Bookify focuses on simplicity, convenience, and a clean interface to make finding and booking a stay quick and straightforward.   
</p>
